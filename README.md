# Vela Studio: релизы

Установщики Vela Studio, Windows-программы для записи экрана и стрима на Twitch.

Скачать: раздел **Releases**, файл `Vela-Studio-Setup-X.Y.Z.exe`.
Установка для текущего пользователя, права администратора не нужны. Установщик не подписан, поэтому Windows SmartScreen при первом запуске может показать предупреждение.

В этом репозитории только установщики и описание версий, без исходного кода.
